Room commands

Mention the agent using the room’s @ dropdown, then describe the incident:

@geetyravi07/incident-memory-agent Checkout requests are timing out in production.

To record a resolution, include every field:

@geetyravi07/incident-memory-agent resolve #12 root cause: exhausted database connections fix: increase the pool limit not worked: restart the service

Use not worked: none if no attempted fix failed.

Report through the local API

With the Flask app running, this PowerShell example creates an incident and returns its ID and page URL:

$body = @{
  title = "Checkout requests are timing out"
  report = "Requests queue until they time out during checkout."
  where_seen = "Production checkout service"
  source = "monitoring"
  reported_by = "On-call engineer"
} | ConvertTo-Json

$headers = @{
  "X-Report-Token" = $env:REPORT_API_TOKEN
}

Invoke-RestMethod `
  -Uri "http://127.0.0.1:5000/api/report" `
  -Method Post `
  -ContentType "application/json" `
  -Headers $headers `
  -Body $body

Set REPORT_API_TOKEN in your PowerShell session to the same value configured for the app. This example does not print it.
